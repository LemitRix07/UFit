## About UFit

UFit is an AI-powered smart fitness and wellness platform designed to make fitness assessment, tracking, and engagement easier for students.

The platform combines AI-based fitness assessment with gamification to encourage students to stay active and build healthy habits. Users can track their fitness progress, participate in challenges, maintain workout streaks, earn points and badges, and compete on leaderboards.

### Key Features

* AI-powered fitness assessment
* Real-time exercise and posture analysis
* Personalized fitness tracking
* Workout streaks and progress monitoring
* Points, badges, and achievement system
* 1v1 fitness challenges
* Leaderboards and student rankings
* Smart alarm and movement-based unlock system
* Faculty dashboard for monitoring student activity
* Fitness analytics and performance reports

### Technology Stack

* Frontend: HTML, CSS, JavaScript / React
* Backend: Python, FastAPI
* AI/ML: MediaPipe, OpenCV, TensorFlow
* Database: MongoDB
* Authentication: Secure user authentication and authorization

### Objective

The main goal of UFit is to turn fitness from a routine activity into an engaging and accountable experience. By combining AI, gamification, and fitness analytics, UFit encourages students to move more, stay consistent, and monitor their overall fitness journey.
